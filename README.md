모바일 환경에 최적화된 모바일 웨딩 청첩장 및 하객별 커스텀 감사 페이지 웹 애플리케이션입니다.

## 🔗 Live Demo

- **웹사이트 바로가기**: [https://minwoo19930301.github.io/wedding/](https://minwoo19930301.github.io/wedding/)

---

## 🎨 주요 기능 (Features)

- 📱 **모바일 퍼스트 인터랙티브 디자인**: 스마트폰 화면 비율에 최적화된 감성 UI 및 카드 레이아웃
- 🎵 **배경음악(BGM) 재생 기능**: 음악과 어우러지는 비주얼 연출 (`music.mp3`)
- 💌 **개인화 감사 카드 (Custom Thanks Pages)**: 혼주 및 가족, 하객 대상별 맞춤 메시지 페이지 제공
- 🌊 **감성 인터랙티브 애니메이션**: 커스텀 CSS (`underwater.css`) 기반의 시각 효과
